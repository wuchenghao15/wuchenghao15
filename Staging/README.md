# MTSCOS AI Project - 灰度测试环境

## 目录说明

- **Backups/**: 测试环境的备份文件
- **Logs/**: 测试环境的日志文件
- **Results/**: 测试结果存储目录
- **Temp/**: 临时文件目录
- **Uploads/**: 上传文件存储目录
- **Scripts/**: 脚本目录
  - **tests/**: 测试脚本
  - **upgrades/**: 升级脚本
  - **maintenance/**: 维护脚本
- **Users/**: 测试用户信息存储

## 注意事项

1. 不要在此环境中存储敏感数据
2. 定期清理过期文件，避免占用过多磁盘空间
3. 所有测试必须在此环境完成后才能部署到生产环境
4. 遵循最小权限原则，限制对此环境的访问
5. 定期备份重要数据到安全位置

## 环境维护

- 日志保留期限: 14天
- 备份保留数量: 5个
- 定期清理: 每天凌晨1点
- 维护计划: 每天凌晨0点
