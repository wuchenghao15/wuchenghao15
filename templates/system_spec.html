§1-§5 · 系统规范 · 《MTSCOS AI 设计规范》SSOT

以下规范为硬性规定，UI/主题/布局相关任何改动不得突破以下约束；若变更须超管审批并同步本文。

§1 布局比例（硬约束）

  • 主页（/，index.html）：Header : Main : Footer ≡ 1 : 7 : 2（即 10vh : 70vh : 20vh，总和 100vh）。
    • Header：flex: 0 0 10vh; max-height: 10vh; min-height: 64px; 顶部永不留白。
    • Main：flex: 0 0 70vh; max-height: 70vh; min-height: 420px; overflow-y: auto; 内容溢出仅在 Main 内部滚动，绝不能把 Footer 顶出比例。
    • Footer：flex: 0 0 20vh; max-height: 20vh; min-height: 180px; order: 999; 高度不得超过 20vh；必须低于所有内容 div（DOM 顺序最后 + z-index 最低 + Guardrails 兜底）。
  • 其他所有页面（base.html）：Sidebar（左） : Main（右） ≡ 2 : 8（20% : 80%）。
    • 用户可点击页眉「侧边栏」按钮切换为图标化（简化模式），此时比例变为 1 : 9（10% : 90%），文本隐藏仅保留图标。
    • Header 在所有页均为 position: sticky; top: 0; z-index: 999;，任何滚动下 Header 必须顶头。

§2.1 设计令牌系统（Design Tokens）

  • 设计原则：去AI味、克制专业、统一规范。去除极光动效、颗粒纹理、发光效果、过度渐变等AI生成特征。
  • 主色系统：
    • --accent: #4f46e5（深靛蓝，核心主色）
    • --accent-soft: rgba(79, 70, 229, 0.12)（主色柔和背景）
    • --accent-hover: rgba(79, 70, 229, 0.22)（主色悬停背景）
    • --accent-text: #6366f1（主色文字）
    • --accent-text-bright: #818cf8（亮主色文字）
    • --accent-secondary: #06b6d4（青色辅色）
  • 功能色：
    • --success: #22c55e / --success-soft
    • --warning: #f59e0b / --warning-soft
    • --danger: #ef4444 / --danger-soft / --danger-text
  • 间距体系（4px基准）：--space-1(4px) / --space-2(8px) / --space-3(12px) / --space-4(16px) / --space-6(24px) / --space-8(32px)
  • 圆角体系（克制）：--radius-sm(8px) / --radius-md(12px) / --radius-full(9999px)
  • 阴影体系（柔和无发光）：--shadow-sm(0 1px 3px) / --shadow-md(0 4px 12px) / --shadow-lg(0 8px 24px)
  • 玻璃拟态（适度模糊）：--glass-blur(12px) / --glass-blur-strong(16px) / --glass-bg/rgba(15,23,42,0.8) / --glass-border/rgba(255,255,255,0.08)
  • 文本色：--text-primary(#f8fafc) / --text-secondary(#cbd5e1) / --text-muted(#94a3b8) / --text-faint(#64748b)
  • 背景：--bg-page(linear-gradient 135deg #0f172a → #1e1b4b) / --bg-card/rgba(15,23,42,0.7) / --bg-card-alt/rgba(15,23,42,0.6)
  • 字体栈：--font-sans(-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif)

§2.1.1 主题变量体系（Theme Variables）

  • 统一主题变量前缀：所有主题变量使用 --theme-* 前缀，定义于 /static/css/theme.css，由首页和基础模板引用。
  • 主色系统：--theme-primary(#4f46e5) / --theme-primary-light(#6366f1) / --theme-primary-dark(#4338ca) / --theme-primary-accent(#06b6d4)
  • 文本色：--theme-text-primary(#f8fafc) / --theme-text-secondary(#cbd5e1) / --theme-text-muted(#94a3b8) / --theme-text-faint(#64748b)
  • 背景色：--theme-bg-page(linear-gradient) / --theme-bg-card/rgba(15,23,42,0.7) / --theme-bg-sidebar/rgba(15,23,42,0.85)
  • 边框色：--theme-border-subtle/rgba(79,70,229,0.1) / --theme-border-strong/rgba(79,70,229,0.18)
  • 功能色：--theme-success(#22c55e) / --theme-warning(#f59e0b) / --theme-danger(#ef4444)
  • 间距体系：--theme-space-1(4px) / --theme-space-2(8px) / --theme-space-4(16px) / --theme-space-6(24px) / --theme-space-8(32px)
  • 使用方式：子组件变量通过 var(--theme-xxx, fallback) 引用统一主题变量，确保主题切换时全站同步。

§2.1.2 千人千面主题推荐

  • 推荐策略：基于时间（日间/夜间）自动推荐主题，API /api/theme/recommend 提供推荐逻辑。
  • 日间（6:00-18:00）：推荐浅色主题（light），减少眼睛疲劳。
  • 夜间（18:00-6:00）：推荐深色主题（deep_blue），保护视力。
  • 用户偏好：用户可在设置页手动选择主题，选择后保存至 localStorage['mtscos_theme'] 和 Session。
  • 超级管理员：可在超级管理员设置页面统一配置系统默认主题，并开启/关闭千人千面推荐功能。

§2.2 组件样式规范

  • 卡片（Card）：background: var(--bg-card); backdrop-filter: blur(var(--glass-blur)); border: 1px solid var(--border-subtle); border-radius: var(--radius-md); box-shadow: var(--shadow-md);
  • 按钮（Button）：
    • 主按钮：background: var(--accent); color: white;
    • 次按钮：background: var(--accent-soft); color: var(--accent-text); border: 1px solid var(--border-subtle);
    • 危险按钮：background: var(--danger); color: white;
  • 输入框（Input）：background: var(--bg-card-alt); border: 1px solid var(--border-subtle); focus时border-color: var(--accent); box-shadow: 0 0 0 3px var(--accent-soft);
  • 标签（Chip/Badge）：padding: var(--space-1) var(--space-3); border-radius: var(--radius-full); 使用对应--xxx-soft背景 + --xxx前景色
  • 表格（Table）：th使用--bg-card-alt背景；tr:hover使用--accent-soft背景；border-bottom使用--border-subtle

§2.3 布局规范

  • 首页布局：Header(10vh) : Main(70vh) : Footer(20vh) ≡ 1:7:2
  • 后台布局：Sidebar(20%) : Main(80%) ≡ 2:8；侧边栏可切换为1:9图标模式
  • 侧边栏折叠：展开宽度220px，缩进宽度64px，状态通过localStorage持久化
  • 滚动策略：内容区域内部滚动，隐藏滚动条；页面无全局滚动
  • 响应式断点：768px（移动端）、1024px（平板）、1280px（桌面）

§2.4 禁用装饰清单（去AI味）

  • 禁止使用极光动效（aurora）、颗粒纹理（grain）、发光效果（glow）
  • 禁止使用渐变文字（-webkit-background-clip: text）
  • 禁止使用脉冲动画（pulse）、浮动动画（float）、弹跳动画（bounce）
  • 禁止使用Emoji作为图标或装饰元素
  • 禁止使用过度渐变背景（超过2色的渐变视为过度）
  • 禁止使用阴影发光效果（box-shadow中rgba alpha值超过0.2视为发光）

§3 国家公祭日主题 · 自动切换规则

  • 触发日期（固定，不可配置）：9/18 九一八、9/30 烈士纪念日、12/13 南京大屠杀死难者国家公祭日。
  • 系统行为：当日 00:00:00 – 23:59:59，服务器端 _resolve_theme() 自动强制返回 mourning，忽略普通用户任何 session 偏好。
  • 普通用户/普通管理员：/api/theme/set 返回 403 公祭日主题为系统自动启用，不可手动切换；设置页的主题项全部 disabled（只读）。
  • 超级管理员（super_admin_approved = 1）：公祭日期间可通过 /api/theme/set 在自己的 session 内写入 theme_override 用于预览；该权限仅限超管，不可下放。
  • 非管理员设置页（/settings）：根本不显示"主题与公祭日"Tab，不存在任何手动切换入口。
  • 管理员设置页（/settings）：仅查看模式；公祭日下拉、主题 chip、自动开关均永久 aria-disabled=true disabled，超管除外多一栏"强制覆盖"按钮区。

§5 合规与回归基线

  • 任何改动后，回归用例必过：
    1. 主页截图：标尺量 Header/Main/Footer 高度比 = 1 : 7 : 2（±1vh 容差）；Footer 与视窗底部无缝隙；无任何 div 在 Footer 之后。
    2. 把系统日期临时模拟为 9/18、9/30、12/13：theme_key == 'mourning' 且非超管调用 /api/theme/set 返回 403；img 全站灰度滤镜生效。
    3. 侧边栏按钮点击两次：20/80 ↔ 10/90，且 localStorage['mtscos_sidebar_mini'] 正确持久化。
    4. 设置页 /settings：非管理员账号进入 → 无"主题与公祭日"Tab；管理员账号进入 → Tab 存在但 chip/下拉全 disabled；超管进入 → 额外出现"强制指定主题覆盖"按钮。

§6 · 使用文档（教师/学生快速开始）

面向教师、学生、管理员三类角色的快速上手指引，覆盖命题、诊断、学情画像、AI答疑等核心能力。

教师端快速开始

  • 登录后进入 /teacher_portal，进入考试与题库系统 → 组卷。
  • 支持 AI 知识图谱标注、难度自适应选题、细粒度能力标签输出。
  • 批改后前往 学情诊断，生成多维度雷达图与薄弱点清单。

学生端快速开始

  • 登录后进入 /student_portal → AI 辅导老师 自适应学习路径。
  • 设置页 /settings 可配置学习目标、通知、隐私与数据导出。
  • 考试入口：/exam_system/exams 支持随到随考、AI 讲解复盘。

§7 · API 接口（对外能力面）

基于 HTTP + JSON 的对外能力面，鉴权使用 Session Cookie + CSRF Token，生产环境建议部署 WSGI + TLS。

方法路径说明权限
POST/api/auth/login账密登录（已挂载正式 DB，验证码已移除）匿名
POST/api/theme/set切换主题；公祭日仅超级管理员可写登录/超管
POST/api/theme/reset清除自定义覆盖，回到系统自动判定登录
GET/api/theme/get获取当前主题及可用主题列表匿名
GET/api/theme/recommend千人千面主题推荐（基于时间）登录
GET/api/user/info当前会话用户/版本/角色信息登录

§8 · 系统规则（会话/安全/权限/审计/数据/VIKEY）

  • 会话：连续 30 分钟无操作自动登出，5 分钟无输入进入锁屏（MTSCOS.lock()）。
  • 安全：账密经 scrypt + salt 存储，登录失败 5 次触发 10 分钟冷却；全程 HTTPS/TLS。
  • 权限：角色分为 学生 / 家长 / 教师 / 校管理员 / 超管 五阶，细粒度由 users.super_admin_approved 与 role 联合判定。
  • 审计：登录/登出、主题切换、敏感数据写入均进入审计表可追溯。
  • 数据：个人数据支持导出（JSON）与删除（GDPR 合规），在 /settings → 数据管理 操作。
  • VIKEY强制规则：VIKEY_FORCE_CHECK_ENABLED=1 — 无论调试模式还是普通模式，超级管理员界面和操作必须插入VIKEY USB加密狗。
  • VIKEY监控：超级管理员页面每2秒检测VIKEY状态，异常时立即快照并锁定系统，5分钟（VIKEY_LOCK_TIMEOUT=300）未插入则退出并释放快照。
  • VIKEY锁定：检测到加密狗拔出后，前端显示"VIKEY USB加密狗状态异常"，重新插入后显示"已插入VIKEY USB硬件加密狗"并恢复快照状态。
  • 调试模式绕过：VIKEY_ALLOW_DEBUG_BYPASS=0 — 不允许在调试模式下绕过VIKEY检测，确保安全策略在所有环境下一致执行。

§9 · 常见问题 FAQ

  • 为什么我进设置看不到"主题与公祭日"？ 你是普通账号（非管理员）；按 §3/§4，非管理员无此入口。
  • 公祭日主题我能不能手动关掉？ 不能。按 §3，任何非超管账号均无法手动切换公祭日与标准主题。
  • 为什么侧边栏比例有时 2:8 有时 1:9？ 你点了页眉的「侧边栏」按钮进入图标模式（§1），再点一次就回去。
  • 忘记密码怎么办？ 前往 /auth/forgot_password 用注册邮箱/手机找回，或联系校管理员重置。
  • 能导出我的学习数据吗？ 可以，/settings → 数据管理 → 导出 JSON 或发起删除申请（GDPR 合规）。
