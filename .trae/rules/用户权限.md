## 5. 权限检查流程

```
1. 用户登录时验证身份
2. 根据用户角色加载权限列表
3. 权限列表缓存到session
4. 访问资源时检查权限缓存
5. 权限变更时刷新缓存
6. 记录权限操作审计日志
7. 超级管理员额外检查VIKEY认证
```

### 5.1 权限检查函数

```python
def has_permission(role, permission):
    """检查角色是否有指定权限"""
    perms = get_role_permissions(role)
    if '*' in perms:
        return True
    return permission in perms

def can_access(role, required_role):
    """检查角色是否可以访问需要特定角色的资源"""
    if role == 'super_admin':
        return True
    return get_role_level(role) >= get_role_level(required_role)
```

### 6.2 审计日志查询

```python
def audit_log(user_id, action, module, resource, status, details):
    """记录审计日志"""
    with self.lock:
        conn = self._get_connection()
        cursor = conn.cursor()
        cursor.execute('''
            INSERT INTO audit_logs 
            (user_id, action, module, resource, status, details, created_at)
            VALUES (?, ?, ?, ?, ?, ?, ?)
        ''', (user_id, action, module, resource, status, details, datetime.now().isoformat()))
        conn.commit()
        conn.close()
```
