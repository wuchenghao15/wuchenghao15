## 3. 交叉引用关系

### 3.1 §14 IRON_RULE（L0最高优先级）
- **所有其他规则必须服从§14 IRON_RULE**
- 任何开发活动（新建功能、修改代码、修复Bug、调整配置）必须先走12步骤
- 参见: [§14强制开发12步骤独立约束规则.md](§14强制开发12步骤独立约束规则.md)

### 3.2 开发规则 → 其他规则
- 开发活动 → 遵循 `开发规则.md` 目录结构和代码规范
- UI开发 → 遵循 `设计规范.md` Element Plus设计Token
- 路由/API → 遵循 `用户权限.md` @system_container装饰器
- AI组件 → 遵循 `AI系统操作规范.md` AI员工/引擎/脑库操作
- 系统功能 → 遵循 `系统操作规范.md` 子系统操作
- 参数管理 → 遵循 `系统参数数据规范与操作规范.md` 参数分类/验证
- 源码修改 → 遵循 `源码修改准则参考与思路方案.md` 修改流程
- 题库管理 → 遵循 `题库管理规范与准则.md` 题目质量/分类

### 3.3 权限规则交叉
- 超级管理员(wuchenghao15): 7要素强认证 + VIKEY加密狗 → 见 `用户权限.md` §1.1
- @system_container装饰器: 4级(guest/login/admin/super_admin) → 见 `用户权限.md` §2
- §14 IRON_RULE: bypass_allowed=False → 禁止任何人绕过，包括超级管理员
