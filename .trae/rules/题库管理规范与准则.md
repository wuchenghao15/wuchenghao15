# MTSCOS AI 项目题库管理规范与准则

## 1. 总则

### 1.1 目的

为规范MTSCOS AI项目题库管理工作，确保题库内容的质量、准确性和完整性，建立统一的题库扩充与维护标准，特制定本规范。

### 1.2 适用范围

本规范适用于MTSCOS AI项目中所有题库管理活动，包括但不限于：
- 题目源管理
- 题目分类与标签管理
- 题目质量检查
- 题库扩充（AI生成与手动添加）
- 题目生命周期管理
- 专项题库管理
- 题库统计与分析

### 1.3 核心原则

| 原则 | 说明 |
|------|------|
| **质量优先** | 所有题目必须经过严格的质量检查才能入库 |
| **分类清晰** | 题目必须按照统一的分类体系进行归类 |
| **标签规范** | 题目必须添加准确的标签便于检索和推荐 |
| **来源可追溯** | 每道题目必须记录来源信息 |
| **定期维护** | 题库内容必须定期更新和清理 |
| **安全合规** | 题库内容必须符合法律法规和教育规范 |
| **巡检驱动** | 题库管理必须纳入AI巡检闭环，支持自动检测和修复 |
| **法律准则合规** | 所有题库管理活动必须遵循法律准则文件规定 |
| **自动修复闭环** | 发现题库问题自动触发修复流程，修复结果记录到数据库并投喂脑库 |

## 5. 题目质量检查规范

### 5.1 质量检查标准

题目必须通过以下质量检查：

| 检查项 | 标准 | 说明 |
|--------|------|------|
| **必填字段检查** | 所有必填字段必须存在且非空 | `id`, `subject`, `question`, `options`, `answer`, `difficulty` |
| **难度验证** | 难度值必须为有效值 | `简单`, `中等`, `困难` |
| **科目验证** | 科目必须为有效科目 | 见3.2节 |
| **题目长度检查** | 题目内容长度必须在10-1000字符之间 | 过短或过长都不符合要求 |
| **选项数量检查** | 选项数量必须在2-6个之间 | 保证题目的有效性 |
| **选项有效性检查** | 每个选项必须非空且为字符串 | 禁止空选项 |
| **答案有效性检查** | 答案必须在选项范围内 | 答案索引或内容必须有效 |
| **解析检查** | 解析内容至少5个字符 | 确保解析有意义 |
| **重复检查** | 题目内容和答案组合必须唯一 | 禁止重复题目 |

### 5.2 质量评分标准

| 评分项 | 权重 | 评分标准 |
|--------|------|---------|
| 题目完整性 | 30% | 所有字段完整得满分，缺失扣减 |
| 题目准确性 | 25% | 题目内容准确无误 |
| 选项合理性 | 20% | 选项具有混淆性，干扰项合理 |
| 解析质量 | 15% | 解析清晰、有指导性 |
| 标签准确性 | 10% | 标签准确反映题目内容 |

**质量等级划分**：
- **优秀**：80分以上
- **良好**：60-79分
- **待优化**：40-59分
- **不合格**：40分以下

### 5.3 质量检查流程

```
提交题目 → 必填字段检查 → 格式验证 → 重复检测 → 质量评分 → 结果判定
                ↓
           检查通过？
              ↓
         是 → 入库
              ↓
         否 → 标记问题 → 返回修改
```

### 5.4 质量问题处理

| 问题类型 | 处理方式 |
|---------|---------|
| 格式错误 | 返回修改，自动标注错误位置 |
| 重复题目 | 拒绝入库，提示重复信息 |
| 质量评分过低 | 返回优化建议，人工审核 |
| 内容错误 | 标记问题，人工审核 |

## 6. 题库扩充流程规范

### 6.1 扩充方式

题库扩充支持以下方式：

| 方式 | 说明 | 适用场景 |
|------|------|---------|
| **AI自动生成** | 由AI员工自动生成题目 | 大规模扩充、专项题库生成 |
| **手动添加** | 人工录入题目 | 少量高质量题目、特殊题型 |
| **批量导入** | 通过文件批量导入题目 | 外部题库整合 |
| **题库同步** | 从教材教辅同步题目 | 与教材同步更新 |

### 6.2 AI生成题目规范

AI生成题目必须遵循以下规范：

| 规范项 | 要求 |
|--------|------|
| **题型多样性** | 必须包含多种题型，不能单一 |
| **难度分布** | 简单:中等:困难 ≈ 3:5:2 |
| **知识点覆盖** | 必须覆盖指定知识点范围 |
| **去重检查** | 生成后必须进行去重检测 |
| **质量评分** | 生成题目必须通过质量评分 |

### 6.3 AI生成专项题目规范

#### 6.3.1 古诗文默写题

| 规范项 | 要求 |
|--------|------|
| 内容来源 | 必须来自经典古诗词库 |
| 出题方式 | 随机挖空，保留上下文 |
| 答案完整性 | 必须包含作者和作品名 |
| 解析要求 | 必须包含作品背景和诗句含义 |

#### 6.3.2 作文题目

| 规范项 | 要求 |
|--------|------|
| 题目类型 | 命题作文、话题作文、材料作文 |
| 字数要求 | 根据学段设置（600/800/1000字） |
| 写作要求 | 明确文体、立意、选材要求 |
| 评分标准 | 提供评分参考维度 |

#### 6.3.3 公式运用题

| 规范项 | 要求 |
|--------|------|
| 公式准确性 | 必须使用正确的公式 |
| 应用场景 | 必须结合实际应用场景 |
| 解题步骤 | 必须提供完整解题步骤 |

### 6.4 审核流程规范

所有新题目必须经过审核才能发布：

```
提交 → AI初检 → 人工审核 → 发布
         ↓
     自动通过/修改/拒绝
```

| 审核级别 | 触发条件 | 审核要求 |
|---------|---------|---------|
| **AI自动审核** | 质量评分≥80分 | 自动通过入库 |
| **人工审核** | 质量评分60-79分 | 人工确认后入库 |
| **重点审核** | 质量评分<60分 | 修改后重新提交 |

## 7. 题目生命周期管理规范

### 7.1 题目状态

| 状态 | 说明 | 操作 |
|------|------|------|
| `draft` | 草稿 | 可编辑、可删除 |
| `pending_review` | 待审核 | 等待审核，不可修改 |
| `approved` | 已审核 | 可发布 |
| `published` | 已发布 | 可使用，可下架 |
| `archived` | 已归档 | 不可使用，可恢复 |
| `deleted` | 已删除 | 不可恢复 |

### 7.2 状态流转

```
draft → pending_review → approved → published → archived/deleted
         ↓                     ↓
    rejected ←←←←←←←←←←←←←←←
```

### 7.3 题目过期管理

| 规则 | 说明 |
|------|------|
| 过期触发 | 题目超过180天未更新自动触发审核 |
| 审核流程 | AI分析 + 人工确认 |
| 处理结果 | 更新内容或标记为过期 |

### 7.4 题目清理规范

| 清理类型 | 条件 | 处理方式 |
|---------|------|---------|
| **质量清理** | 质量评分<40分 | 自动标记待优化 |
| **过期清理** | 超过有效期且未更新 | 自动归档 |
| **重复清理** | 检测到重复 | 保留高质量版本 |

## 11. 题库管理AI规范

### 11.1 AI员工职责

| AI员工 | 职责 |
|--------|------|
| **题目生成员工** | 自动生成各类题目 |
| **题库维护员工** | 检测重复、验证质量、清理题目 |
| **题库管理AI** | 管理题库规则、维护更新、扩充题库 |
| **质量检查员工** | 执行题目质量检查任务 |

### 11.2 AI操作规范

| 规范项 | 要求 |
|--------|------|
| **操作日志** | 所有AI操作必须记录日志 |
| **错误处理** | AI操作失败必须报告并记录到数据库 |
| **结果验证** | AI生成结果必须经过验证才能入库 |
| **智能发现** | AI必须持续发现题目质量问题和扩充机会 |

### 11.3 AI学习机制

| 机制 | 说明 |
|------|------|
| **错误案例共享** | 将错误修复案例共享到知识脑库 |

## 14. 题库巡检规范

### 14.1 巡检驱动的题库管理

| 原则 | 说明 |
|------|------|
| **巡检优先** | 所有题库变更必须通过AI巡检引擎检查 |
| **自动修复** | 检测到的题库问题自动触发修复流程 |
| **法律准则合规** | 所有题库管理活动必须遵循法律准则文件规定 |
| **错误上报** | 题库错误自动上报到数据库 |
| **学习闭环** | 修复经验自动积累到脑库 |

### 14.2 题库巡检检查项

| 检查项 | 说明 | 严重程度 |
|--------|------|----------|
| 题目格式检查 | 题目格式是否符合规范 | 高 |
| 题目完整性检查 | 必填字段是否完整 | 高 |
| 题目质量检查 | 题目质量评分是否达标 | 高 |
| 题目重复检查 | 是否存在重复题目 | 高 |
| 标签准确性检查 | 标签是否准确反映题目内容 | 中 |
| 分类正确性检查 | 题目分类是否正确 | 中 |
| 难度合理性检查 | 难度设置是否合理 | 中 |
| 来源可追溯检查 | 题目来源是否可追溯 | 低 |
| 题目时效性检查 | 题目是否过期或过时 | 中 |
| 答案正确性检查 | 标准答案是否正确 | 高 |
| 解析完整性检查 | 题目解析是否完整 | 中 |
| 合规性检查 | 题目内容是否符合法律法规 | 高 |

### 14.3 题库巡检流程

```
1. 题目入库或更新提交
2. AI巡检引擎扫描题目内容
3. 检测题目格式、质量、完整性、重复性
4. 发现问题自动记录到数据库
5. 触发自动修复流程（如格式错误自动修正）
6. 修复结果记录到脑库
7. 生成题库巡检报告
```

### 14.4 题库巡检API

| API | 方法 | 说明 | 权限 |
|-----|------|------|------|
| `/api/question_bank/inspect` | POST | 检查题库合规性 | question_manager+ |
| `/api/question_bank/fix` | POST | 自动修复题库问题 | question_manager+ |
| `/api/question_bank/report` | GET | 获取题库巡检报告 | admin+ |
