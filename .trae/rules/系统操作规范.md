# MTSCOS AI 系统操作规范

## 1. 概述

### 1.1 文档目的
本文档定义MTSCOS AI系统中所有功能子系统的操作规则，包括创建、升级、维护、修改的标准流程和约束条件。所有系统操作必须优先参考并严格执行本规范。

### 1.2 系统架构

```
MTSCOS AI系统
├── AI系统层
│   ├── AI员工层
│   ├── AI引擎层
│   ├── AI集群层
│   ├── AI阵列层
│   ├── AI神经元网络
│   └── AI脑库
├── 业务系统层
│   ├── 考试系统
│   ├── 学习系统
│   ├── 题库系统
│   └── 用户管理系统
├── 基础设施层
│   ├── 端口管理系统
│   ├── Git同步系统
│   ├── 监控系统
│   └── 数据库系统
└── 前端展示层
    ├── 响应式页面
    ├── 移动端适配
    └── 管理后台
```

### 1.3 核心原则

| 原则 | 说明 |
|------|------|
| **数据持久化优先** | 所有配置、状态、数据必须持久化到数据库 |
| **写穿机制** | 操作后立即同步到数据库，确保数据一致性 |
| **向后兼容** | 修改必须保持向后兼容，不破坏现有功能 |
| **权限控制** | 操作必须遵循用户权限规则 |
| **日志记录** | 所有操作必须记录详细日志 |
| **安全优先** | 任何修改必须确保系统稳定性和数据安全 |
| **巡检驱动** | 所有系统操作必须纳入AI巡检闭环，支持自动检测和修复 |
| **法律准则合规** | 所有系统操作必须严格遵循法律准则文件规定 |
| **自动修复闭环** | 发现问题自动触发修复流程，修复结果记录到数据库并投喂脑库 |

```
考试系统

│   ├── 考试创建/编辑/删除
│   ├── 考试状态管理
│   └── 考试配置
├── 组卷系统
│   ├── AI自动组卷
│   ├── 手动组卷
│   └── 试卷预览
├── 考试执行
│   ├── 在线考试
│   ├── 监考监控
│   └── 防作弊机制
└── 成绩管理
    ├── 自动阅卷
    ├── 成绩统计
    └── 成绩分析
```

### 2.2 考试创建规则

#### 2.2.1 必须属性

| 属性 | 类型 | 说明 | 必填 |
|------|------|------|------|
| exam_id | TEXT | 考试唯一标识 | ✅ |
| exam_name | TEXT | 考试名称 | ✅ |
| subject | TEXT | 科目 | ✅ |
| duration | INTEGER | 考试时长(分钟) | ✅ |
| total_score | INTEGER | 总分 | ✅ |
| difficulty | TEXT | 难度(easy/medium/hard) | ✅ |
| status | TEXT | 状态(draft/published/ongoing/finished) | ✅ |
| start_time | TEXT | 开始时间 | ✅ |
| end_time | TEXT | 结束时间 | ✅ |

#### 2.2.2 创建流程

```
1. 验证权限（admin及以上）
2. 验证考试信息完整性
3. 检查时间冲突
4. 生成exam_id
5. 保存到数据库(exams表)
6. 记录操作日志
7. 通知相关用户
```

#### 2.2.3 状态转换规则

| 当前状态 | 目标状态 | 转换条件 |
|---------|---------|---------|
| draft | published | 管理员发布 |
| published | ongoing | 到达开始时间 |
| ongoing | finished | 到达结束时间或手动结束 |
| finished | draft | 管理员重置 |

### 2.3 组卷规则

#### 2.3.1 AI自动组卷参数

| 参数 | 类型 | 说明 | 默认值 |
|------|------|------|--------|
| subject | TEXT | 科目 | 必填 |
| total_questions | INTEGER | 题目总数 | 50 |
| difficulty_ratio | JSON | 难度比例 | {"easy":0.3,"medium":0.5,"hard":0.2} |
| type_ratio | JSON | 题型比例 | {"单选题":0.4,"多选题":0.2,"判断题":0.2,"填空题":0.1,"简答题":0.1} |
| total_score | INTEGER | 总分 | 100 |

#### 2.3.2 组卷质量要求

| 指标 | 要求 |
|------|------|
| 知识覆盖率 | ≥80% |
| 难度均衡 | 符合设定比例 |
| 题型均衡 | 符合设定比例 |
| 无重复题目 | 同一试卷无重复 |

### 2.4 考试执行规则

#### 2.4.1 考试准入条件

| 条件 | 说明 |
|------|------|
| 登录状态 | 必须登录 |
| 角色权限 | 仅限student/student_vip角色 |
| 教育类型 | 成人教育学生只能参加成人教育科目考试 |
| 时间范围 | 必须在考试时间范围内 |
| 考试次数 | 未超过最大考试次数 |

#### 2.4.2 监考监控规则

| 监控项 | 频率 | 告警条件 |
|--------|------|---------|
| 屏幕切换 | 实时 | 频繁切换告警 |
| 网络状态 | 每30秒 | 网络中断超过1分钟告警 |
| 答题进度 | 每5分钟 | 进度异常告警 |
| 异常行为 | 实时 | 检测到作弊行为告警 |

### 2.5 成绩管理规则

#### 2.5.1 自动阅卷规则

| 题型 | 阅卷方式 |
|------|---------|
| 单选题 | 自动比对答案 |
| 多选题 | 自动比对答案（全对才得分） |
| 判断题 | 自动比对答案 |
| 填空题 | 关键词匹配 |
| 简答题 | AI评分 + 人工复核 |

#### 2.5.2 成绩统计规则

| 统计项 | 说明 |
|--------|------|
| 平均分 | 所有考生平均分 |
| 及格率 | 及格人数/总人数 |
| 最高分 | 最高得分 |
| 最低分 | 最低得分 |
| 标准差 | 分数分布标准差 |
