# 行为准则

## 我们的承诺

为营造开放、友好、包容的环境，我们作为贡献者和维护者承诺：让每个人都能在没有骚扰的环境中参与我们的项目与社区。

## 我们的标准

有助于营造积极环境的行为：

- 使用友好且包容的语言
- 尊重不同的观点与经验
- 优雅地接受建设性批评
- 关注对社区整体最有利的事项
- 对其他社区成员展现同理心

不可接受的行为：

- 使用性化语言或图像，以及任何不受欢迎的性关注或骚扰
- 侮辱性、贬低性评论，人身攻击或政治攻击
- 公开或私下骚扰他人
- 未经明确许可发布他人的私人信息（如物理地址或电子邮箱）
- 其他在专业环境中明显不当的行为

## 维护者责任

项目维护者负责澄清行为准则的标准，并对其认为不符合本准则的行为采取适当且公平的纠正措施。

项目维护者有权删除、编辑或拒绝与本行为准则不符的评论、提交、代码、Wiki 编辑、Issue 及其他贡献，并在必要时说明做出这些决定的原因。

## 范围

本行为准则适用于所有项目空间。当个人在公共空间代表项目或其社区时同样适用，例如：使用官方项目邮箱、通过官方社交媒体账号发声，或在在线/线下活动中担任指定代表。

## 执行

如发现滥用、骚扰或其他不可接受的行为，可通过 [INSERT CONTACT METHOD] 报告。所有投诉都将被审查与调查，并做出适当回应。项目团队有义务对事件报告者保密。

违反本行为准则可能导致临时或永久禁止参与项目。
