### 1.3 模块划分原则

1. **高内聚低耦合**: 单一职责，模块间接口清晰
2. **可独立测试**: 每个模块可单独运行和测试
3. **可独立部署**: 支持模块化发布和灰度
4. **可替换**: 模块可替换为更好的实现
5. **无循环依赖**: 严格禁止模块间循环依赖

#### 2.3.2 异步处理规范

```javascript
// ✅ 推荐：async/await + try-catch
async function fetchData() {
    try {
        const response = await fetch('/api/data');
        if (!response.ok) throw new Error('请求失败');
        return await response.json();
    } catch (error) {
        console.error('数据加载失败:', error);
        throw error;
    }
}

// ❌ 禁止：回调地狱
fetch('/a', a => {
    fetch('/b', b => {
        fetch('/c', c => { /* ... */ });
    });
});
```

#### 2.3.3 API调用规范

```javascript
// 统一响应格式: { success: boolean, message: string, data: any }
async function apiCall(url, options = {}) {
    const response = await fetch(url, {
        headers: { 'Content-Type': 'application/json', ...options.headers },
        ...options
    });
    return await response.json();
}
```

## 5. 数据库规范

> **架构说明**：当前采用分布式 SQLite 分片架构，共 9+ 独立分片、87 张表（0 空表），通过透明路由访问。MySQL 作为可选方案保留兼容。

### 5.1 设计规范

| 项目 | 规范 |
|------|------|
| 表名 | 小写下划线，复数形式 `users` `exam_results` |
| 字段名 | 小写下划线 `created_at` `user_name` |
| 主键 | 统一 `id INTEGER PRIMARY KEY AUTOINCREMENT`（SQLite）/ `BIGINT`（MySQL） |
| 时间字段 | 必须有 `created_at` `updated_at` DATETIME |
| 逻辑删除 | 软删除使用 `is_deleted INTEGER DEFAULT 0`（SQLite）/ `TINYINT`（MySQL） |
| 索引 | 查询条件字段、外键、常排序字段必须建索引 |
| 字符集 | UTF-8（SQLite 默认支持；MySQL 使用 utf8mb4） |
| 存储引擎 | SQLite（默认）；InnoDB（MySQL 可选） |

### 5.2 优化规范

```sql
-- ✅ 使用EXPLAIN分析查询
EXPLAIN SELECT * FROM users WHERE username = 'test';

-- ✅ 避免全表扫描，使用LIMIT分页
SELECT * FROM large_table WHERE id > ? ORDER BY id LIMIT 1000;

-- ❌ 禁止无WHERE的全表查询
SELECT * FROM huge_table;

-- ❌ 禁止SELECT *
SELECT id, name, email FROM users;
```

## 6. 安全规范

### 6.1 认证授权规范

| 项目 | 规范 |
|------|------|
| 密码哈希 | bcrypt 成本因子 >= 12 |
| JWT令牌 | HS256算法，2小时过期，刷新令牌7天 |
| 令牌存储 | HttpOnly + Secure + SameSite Cookie |
| 权限检查 | 每个接口必须校验RBAC权限 |
| 登录安全 | 5次失败锁定15分钟，异地登录告警 |
| 会话管理 | 支持强制下线，单设备登录（可选） |

### 6.2 输入输出安全

```python
# ✅ 输入校验：使用schema
from pydantic import BaseModel, EmailStr, constr

class LoginRequest(BaseModel):
    username: constr(min_length=3, max_length=50)
    password: constr(min_length=8, max_length=128)

# ✅ 输出转义：Flask自动escape + 手动清洗
```

### 6.3 CORS和安全头

```python
# 安全响应头配置
@app.after_request
def set_security_headers(response):
    response.headers['X-Content-Type-Options'] = 'nosniff'
    response.headers['X-Frame-Options'] = 'DENY'
    response.headers['X-XSS-Protection'] = '1; mode=block'
    response.headers['Strict-Transport-Security'] = 'max-age=31536000; includeSubDomains'
```
