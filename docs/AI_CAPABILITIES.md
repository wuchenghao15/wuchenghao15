```
优先级 = 基础权重 × 难度系数 × 年级系数 × 薄弱环节加成 × 偏好加成

其中：
- 基础权重: 语文/数学=1.5, 英语=1.3, 其他=1.0
- 难度系数: easy=0.8, medium=1.0, hard=1.2
- 年级系数: 年级/6 (最高1.5)
- 薄弱环节加成: ×1.5
- 偏好加成: +(偏好次数×0.1)
```

## 🚀 部署方式

### 启动命令

```bash
# 启动AI引擎服务
python3 -m flask-app.ai_engines.ai_learning_recommender

# 启动自适应学习引擎
python3 -m flask-app.ai_engines.ai_adaptive_learning_engine

# 启动完整AI服务
python3 -m flask-app.ai_engines.start_all_ai_employees
```

### 配置说明

```python
# AI引擎配置
AI_CONFIG = {
    'version': '3.0.0',
    'recommendation_count': 5,
    'plan_days': 7,
    'difficulty_adjust_interval': 10,  # 每10次答题调整难度
    'mastery_threshold': 0.7,  # 掌握程度阈值
    'cache_enabled': True,
    'cache_ttl': 3600  # 缓存时间（秒）
}
```
