# 1️⃣ 系统概览

## 项目简介

MTSCOS AI是一个**AI驱动的智能考试系统**，集成了41+个AI员工、6+个AI Agent、590+个检索模型，为教育领域提供全方位的智能化解决方案。

>       - uses: docker://marpteam/marp-cli:latest
>         with:
>           args: docs/presentation/feature-intro.md --pdf --output docs/presentation/feature-intro.pdf
>       - uses: EndBug/add-and-commit@v9
