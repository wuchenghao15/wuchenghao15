# MTSCOS 登录系统

## 项目概述
MTSCOS登录系统是一个安全、高效、用户友好的登录解决方案，支持多因素认证、第三方登录和主题切换等功能。系统采用现代化前端技术构建，具备完善的安全机制和优秀的用户体验。

## 系统版本
当前版本：2.251031.113000

## 功能特性

### 1. 核心登录功能
- 用户名/密码登录认证
- 四位随机数字验证码验证机制
- Vikey认证码支持（通过ivikey.com获取）
- 记住登录状态选项
- 表单实时验证和错误提示

### 2. 第三方登录支持
- GitHub OAuth登录
- Google OAuth登录
- QQ开放平台登录
- WeChat微信扫码登录
- Hotmail/Outlook登录

### 3. 安全机制
- 密码MD5加密存储和传输
- Cookie防盗链保护（带时间戳和随机值的Base64编码）
- Session会话管理和30分钟自动超时
- 网络状态监控和断线提示
- 详细的用户操作日志记录
- 防重复提交机制

### 4. 用户界面
- 蓝色主题和深色主题手动切换
- 公祭日自动切换褐色主题
- 完全响应式设计，适配桌面、平板和移动设备
- 实时时间和时区显示（24小时制）
- 平滑的动画效果和交互反馈
- 夜间模式自动切换

### 5. 智能功能
- 基于地理位置的时区自动检测
- 根据日落时间自动切换暗色主题
- 中华人民共和国国家公祭日自动识别和主题适配
- 浏览器语言检测和多语言支持

## 安全特性详解

### 密码安全
- 客户端MD5加密，服务端二次校验
- 密码复杂度检测
- 防暴力破解机制

### 防盗链与CSRF防护
- 动态生成的防盗链Cookie
- SameSite=Strict Cookie策略
- Secure Cookie属性（HTTPS环境）
- 30分钟自动过期时间

### 会话管理
- 基于用户活动的会话续期
- 页面卸载时清理会话资源
- 会话超时自动登出和错误提示
- 登录状态持久化管理

### 验证码系统
- 四位随机数字生成
- 基于Canvas的动态验证码图像
- 点击刷新功能
- 会话级别的验证码存储

## 主题系统实现

### 主题配置
- 蓝色主题：专业、信任感（默认）
- 深色主题：护眼、夜间使用友好
- 公祭日褐色主题：庄重、纪念性

### 自动适配机制
- 基于系统时间的日落模式检测（18:00-06:00自动暗色）

## 使用指南

### 测试账户
- 用户名：demo
- 密码：password

### 标准登录流程
1. 访问 `HTML/login.html` 页面
2. 输入用户名和密码
3. 输入验证码图片中的四位数字
4. 如需额外安全验证，点击"获取Vikey"并输入认证码
5. 点击"登录"按钮完成认证
6. 登录成功后自动跳转到default.html

### 第三方登录操作
1. 点击相应的社交登录按钮（GitHub/Google/QQ/WeChat/Hotmail）
2. 系统会打开第三方授权页面
3. 完成第三方平台的授权确认
4. 授权成功后自动返回系统并完成登录

### Vikey认证流程
1. 在登录页面点击"获取Vikey"按钮
2. 系统自动打开ivikey.com官网
3. 在官网获取Vikey认证码
4. 将认证码输入到登录页面的Vikey输入框
5. 继续完成登录流程

## 错误处理与日志

### 错误代码说明
- ERR_INVALID_CREDENTIALS: 用户名或密码错误
- ERR_INVALID_CAPTCHA: 验证码不匹配
- ERR_INVALID_VIKEY: Vikey认证码无效
- ERR_SESSION_TIMEOUT: 用户会话已超时
- ERR_NETWORK_ERROR: 网络连接异常
- ERR_SERVER_ERROR: 服务器响应错误

### 日志记录机制
系统会记录以下操作类型：
- 登录尝试（成功/失败及原因）
- 第三方登录授权流程
- Vikey认证码请求
- 忘记密码页面访问
- 主题切换操作
- 页面访问统计和会话信息
- 错误事件和异常情况
