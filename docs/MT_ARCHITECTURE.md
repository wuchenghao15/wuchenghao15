## 1. 架构概述

### 1.1 架构定义

**MTS 架构（MTSCOS Twin-Synergy Architecture）** 是 MTSCOS AI 智能考试系统的第二代核心技术架构——双引擎分层协作架构（命题诊断双核调度）。

### 1.2 架构定位

| 维度 | 描述 |
|------|------|
| **系统类型** | 分布式智能教育平台 |
| **核心定位** | AI 驱动的智能考试与学习管理系统 |
| **技术栈** | Python 3.9+, Flask 3.x, SQLite/MySQL, JavaScript, HTML5, CSS3 |
| **部署模式** | 单体应用 + 分布式数据库 + AI 集群 |

### 1.3 架构特性

- **MTS 双引擎核心**: 命题引擎 + 诊断引擎双核调度，智能出题与学情分析双向赋能
- **AI 自我进化**: 内置 AI 自我学习系统 v2.0，自动从网络获取知识，持续壮大脑库（69+条 → 340+条/周期）
- **分布式架构**: 9+ 独立 SQLite 分片（87 张表，0 空表），支持影子节点 + 数据副本 3 因子
- **高可用设计**: 集群管理、健康检查、自动故障转移、灰度发布 10%
- **安全优先**: VIKEY 硬件密钥 7 要素强认证、AI 防火墙 360° 扫描、多层次安全防护、权限管理体系
- **模块化设计**: 550+ 核心 AI 引擎/员工矩阵与 47 个 Agent，支持独立部署和扩展
- **LayoutAI 排版调节**: LayoutAdjusterAI 员工 20 条割裂检测规则（LF001-LF020）
- **公祭日自动主题**: 国家公祭日自动切换黑灰追思主题

## 2. 设计哲学

### 2.1 核心原则

**1. AI 优先（AI-First）**
- 所有核心业务逻辑均由 AI 引擎驱动
- AI 自我学习系统实现知识自动更新

**2. 模块化架构（Modular Architecture）**
- 每个功能模块独立封装
- 模块间通过 API 和事件总线通信

**3. 分布式思维（Distributed Thinking）**
- 数据库按业务域划分
- AI 引擎支持集群部署

**4. 自我进化（Self-Evolution）**
- AI 自动发现学习方向
- 自动生成学习规则
- 持续优化系统性能

**5. 安全内置（Security by Design）**
- 权限控制嵌入架构底层
- 敏感数据加密存储
- 漏洞自动扫描修复

### 2.2 架构愿景

```text
┌─────────────────────────────────────────────────────────────────┐
│                        愿景目标                                 │
├─────────────────────────────────────────────────────────────────┤
│  AI 自我进化 → 知识自动获取 → 系统持续优化 → 用户体验提升         │
├─────────────────────────────────────────────────────────────────┤
│  学习领域: AI | Architecture | Database | Security | DevOps     │
│  学习周期: 每 30 分钟自动执行                                      │
```

## 3. 分层架构

### 3.1 四层架构模型

```text
┌─────────────────────────────────────────────────────────────────┐
│                    第 1 层: 表现层 (Presentation Layer)            │
│  ┌───────────────────────────────────────────────────────────┐ │
│  │  Web 界面 | 移动端 | API 网关 | 仪表盘 | 管理后台             │ │
│  └───────────────────────────────────────────────────────────┘ │
├─────────────────────────────────────────────────────────────────┤
│                    第 2 层: 业务层 (Business Layer)               │
│  ┌───────────────────────────────────────────────────────────┐ │
│  │  AI 引擎矩阵 | 业务服务 | 规则引擎 | 工作流编排 | 权限管理    │ │
│  └───────────────────────────────────────────────────────────┘ │
├─────────────────────────────────────────────────────────────────┤
│                    第 3 层: 数据层 (Data Layer)                    │
│  ┌───────────────────────────────────────────────────────────┐ │
│  │  分布式数据库 | 知识图谱 | 向量存储 | 缓存层 | 文件存储      │ │
│  └───────────────────────────────────────────────────────────┘ │
├─────────────────────────────────────────────────────────────────┤
│                    第 4 层: 基础设施层 (Infrastructure Layer)      │
│  ┌───────────────────────────────────────────────────────────┐ │
│  │  服务器集群 | 容器编排 | 网络通信 | 安全防护 | 监控告警      │ │
│  └───────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────────┘
```

### 3.2 各层详解

#### 3.2.1 表现层

| 组件 | 功能 | 技术实现 |
|------|------|----------|
| Web 界面 | 桌面端用户交互 | HTML5 + CSS3 + JavaScript |
| 移动端 | 响应式适配 | Tailwind CSS + Media Queries |
| API 网关 | RESTful API 统一入口 | Flask Blueprint |
| 仪表盘 | 系统状态可视化 | Chart.js + 自定义组件 |
| 管理后台 | 管理员操作界面 | Jinja2 模板 + Element Plus |

#### 3.2.2 业务层

| 组件 | 功能 | 核心模块 |
|------|------|----------|
| AI 引擎矩阵 | 550+ 核心 AI 引擎/员工 + 47 Agent | 自我学习、智能出题、作业批改、学习诊断 |
| 业务服务 | 业务逻辑封装 | 考试管理、用户管理、课程管理 |
| 规则引擎 | 动态规则执行 | 权限规则、业务规则、学习规则 |
| 工作流编排 | 流程自动化 | AI 工作流、审批流程 |
| 权限管理 | RBAC 权限控制 | 16 角色、6 级访问控制 |

#### 3.2.3 数据层

| 组件 | 功能 | 技术选型 |
|------|------|----------|
| 分布式数据库 | 9+ 独立 SQLite 分片（87 张表） | SQLite/MySQL |
| 知识图谱 | 知识关联存储 | 自定义图数据库 |
| 向量存储 | AI 语义检索 | 向量数据库引擎 |
| 缓存层 | 性能优化 | Redis/Memcached |
| 文件存储 | 静态资源管理 | 本地存储/云存储 |

#### 3.2.4 基础设施层

| 组件 | 功能 | 技术实现 |
|------|------|----------|
| 服务器集群 | 负载均衡 | Nginx + 多节点部署 |
| 容器编排 | Docker 容器管理 | Docker Compose |
| 网络通信 | 内部服务通信 | HTTP/HTTPS |
| 安全防护 | 防火墙 + SSL | Let's Encrypt |
| 监控告警 | 系统健康监控 | 自定义监控服务 |

### 4.2 核心引擎详解

#### 4.2.1 自我学习引擎

**架构定位**: AI 自我进化的核心引擎

**核心组件**:

```text
自我学习引擎
├── KnowledgeQualityEvaluator    # 知识质量评估器
├── NetworkKnowledgeFetcher      # 网络知识获取器
├── UpgradeMaintenanceLearner    # 升级维护学习器
├── LearningDirectionDiscoverer  # 学习方向发现器
├── RulesWriter                  # 规则写入器
├── BrainDatabaseManager         # 脑库数据库管理器
└── LearningPolicyExecutor       # 学习政策执行器
```

**学习机制**:
- **自动学习**: 每 30 分钟自动执行学习循环
- **网络学习**: 从维基百科、GitHub 等来源获取知识
- **维护学习**: 从错误修复和系统升级中学习
- **规则生成**: 自动发现学习方向并生成规则
- **知识存储**: 存储到脑库数据库

**当前状态**:
- 知识数量: 69+ 条
- 规则数量: 10 条
- 学习领域: 7 个（AI、Architecture、Database、Security、Performance、DevOps、Flask）
