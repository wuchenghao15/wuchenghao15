## 1. 架构概述

### 1.1 架构定义

**MTS架构（MTSCOS Twin-Synergy Architecture）** 是MTSCOS AI智能考试系统的第二代核心技术架构——双引擎分层协作架构（命题诊断双核调度）

### 1.2 架构定位

| 维度 | 描述 |
|------|------|
| **系统类型** | 分布式智能教育平台 |
| **核心定位** | AI驱动的智能考试与学习管理系统 |
| **技术栈** | Python 3.11+, Flask 3.0+, SQLite/MySQL, JavaScript, HTML5, CSS3 |
| **部署模式** | 单体应用 + 分布式数据库 + AI集群 |

### 1.3 架构特性

- **MTS双引擎核心**: 命题引擎 + 诊断引擎双核调度，智能出题与学情分析双向赋能
- **AI自我进化**: 内置AI自我学习系统v2.0，自动从网络获取知识，持续壮大脑库（69+条→340+条/周期）
- **分布式架构**: 20+独立数据库，支持影子节点+数据副本3因子
- **高可用设计**: 集群管理、健康检查、自动故障转移、灰度发布10%
- **安全优先**: VIKEY硬件密钥7要素强认证、AI防火墙360°扫描、多层次安全防护、权限管理体系
- **模块化设计**: 41+核心AI引擎矩阵，支持独立部署和扩展
- **LayoutAI排版调节**: LayoutAdjusterAI员工20条割裂检测规则（LF001-LF020）
- **公祭日自动主题**: 国家公祭日自动切换黑灰追思主题

## 2. 设计哲学

### 2.1 核心原则

**1. AI优先（AI-First）**
- 所有核心业务逻辑均由AI引擎驱动
- AI自我学习系统实现知识自动更新

**2. 模块化架构（Modular Architecture）**
- 每个功能模块独立封装
- 模块间通过API和事件总线通信

**3. 分布式思维（Distributed Thinking）**
- 数据库按业务域划分
- AI引擎支持集群部署

**4. 自我进化（Self-Evolution）**
- AI自动发现学习方向
- 自动生成学习规则
- 持续优化系统性能

**5. 安全内置（Security by Design）**
- 权限控制嵌入架构底层
- 敏感数据加密存储
- 漏洞自动扫描修复

### 2.2 架构愿景

```
┌─────────────────────────────────────────────────────────────────┐
│                        愿景目标                                  │
├─────────────────────────────────────────────────────────────────┤
│  AI自我进化 → 知识自动获取 → 系统持续优化 → 用户体验提升          │
├─────────────────────────────────────────────────────────────────┤
│  学习领域: AI | Architecture | Database | Security | DevOps    │
│  学习周期: 每30分钟自动执行                                      │
│  知识增长: 持续累计，当前69+条                                   │
└─────────────────────────────────────────────────────────────────┘
```

### 4.2 核心引擎详解

#### 4.2.1 自我学习引擎

**架构定位**: AI自我进化的核心引擎

**核心组件**:
```
自我学习引擎
├── KnowledgeQualityEvaluator    # 知识质量评估器
├── NetworkKnowledgeFetcher      # 网络知识获取器
├── UpgradeMaintenanceLearner    # 升级维护学习器
├── LearningDirectionDiscoverer  # 学习方向发现器
├── RulesWriter                  # 规则写入器
├── BrainDatabaseManager         # 脑库数据库管理器
└── LearningPolicyExecutor       # 学习政策执行器
```

**学习机制**:
- **自动学习**: 每30分钟自动执行学习循环
- **网络学习**: 从维基百科、GitHub等来源获取知识
- **维护学习**: 从错误修复和系统升级中学习
- **规则生成**: 自动发现学习方向并生成规则
- **知识存储**: 存储到脑库数据库

**当前状态**:
- 知识数量: 69+条
- 规则数量: 10条
- 学习领域: 7个（AI、Architecture、Database、Security、Performance、DevOps、Flask）
