# MTSCOS AI 项目监控与自动化管理使用说明

## 概述

本项目提供了一套完整的监控与自动化管理系统，用于持续监控项目状态、自动修复问题、更新版本、管理文档、清理文件和创建备份。

## 核心组件

### 1. 监控脚本 (monitor.sh)

**功能**：
- 持续监控 Node.js 进程状态
- 检查端口占用情况
- 验证核心文件完整性
- 检查 npm 依赖状态
- 分析错误日志
- 自动修复常见问题
- 定期执行自动化管理任务

**使用方式**：

```bash
# 运行单次监控检查
./monitor.sh --once 或 ./monitor.sh -o

# 启动持续监控（默认1小时间隔）
./monitor.sh --continuous 或 ./monitor.sh -c

# 立即运行自动化管理任务
./monitor.sh --automated 或 ./monitor.sh -a
```

### 2. 自动化管理脚本 (automated-management.sh)

**功能**：
- **版本管理**：自动更新项目版本号、构建号和发布日期
- **文档更新**：自动更新 README.md 和 CHANGELOG.md
- **错误修复**：检查并修复 JavaScript、HTML 和 CSS 语法错误
- **项目归类**：自动创建和维护标准目录结构，归类核心文件
- **文件清理**：清理临时文件、过期日志、空目录和重复文件
- **备份管理**：创建完整备份、差异备份，并清理旧备份
- **报告生成**：生成详细的自动化管理报告

**使用方式**：

```bash
# 直接运行
./automated-management.sh

# 或通过监控脚本定期执行
```

### 3. 启动脚本 (start-monitor.sh)

**功能**：提供交互式界面，方便用户选择监控操作

**使用方式**：

```bash
./start-monitor.sh
```

## 配置说明

### 监控脚本配置 (monitor.sh)

| 配置项 | 默认值 | 说明 |
|-------|-------|------|
| MONITOR_INTERVAL | 3600 | 监控间隔（秒） |
| RUN_AUTOMATED_EVERY | 24 | 自动化管理运行间隔（小时） |
| MAX_LOG_SIZE | 10485760 | 日志最大大小（字节） |
| MAX_BACKUP_LOGS | 5 | 日志备份数量 |

### 自动化管理配置 (automated-management.sh)

| 配置项 | 默认值 | 说明 |
|-------|-------|------|
| MAX_OLD_FILE_AGE | 180 | 旧文件清理天数 |
| BACKUP_RETENTION | 7 | 备份保留天数 |

## 自动化管理流程

1. **版本更新**：
   - 更新 package.json 版本号
   - 更新统一版本管理器版本
   - 更新核心 JS 文件版本
   - 更新 README.md 和 CHANGELOG.md

2. **错误修复**：
   - 修复文件权限
   - 检查并修复 JavaScript 语法错误
   - 检查 HTML 和 CSS 语法
   - 验证 npm 依赖

3. **项目归类**：
   - 创建标准目录结构
   - 归类核心 JS 文件
   - 归类页面脚本和工具脚本
   - 设置目录权限

4. **文件清理**：
   - 清理旧临时文件
   - 清理过期日志
   - 清理空目录
   - 检查并清理重复文件
   - 检查 node_modules 状态
   - 清理构建目录和缓存

5. **备份管理**：
   - 备份配置文件
   - 备份核心代码
   - 备份依赖配置
   - 备份数据库文件
   - 创建压缩备份
   - 清理旧备份

6. **报告生成**：
   - 系统资源状态
   - 项目文件状态
   - 自动化操作执行情况
   - 日志摘要
   - 安全检查结果
   - 性能优化建议

## 日志管理

- **监控日志**：`Logs/monitor.log`
- **错误日志**：`Logs/error.log`
- **自动化管理日志**：`Logs/automated-management.log`
- **自动化报告**：`Logs/automated_report_YYYYMMDD_HHMMSS.md`

```bash
./monitor.sh --automated
```

## 注意事项

1. **权限要求**：确保脚本有执行权限（可通过 `chmod +x script_name.sh` 设置）
2. **日志管理**：定期检查日志文件，避免磁盘空间占用过大
3. **备份策略**：根据项目需求调整备份保留天数
4. **监控间隔**：根据服务器性能调整监控间隔
5. **自动化频率**：根据项目更新频率调整自动化管理运行间隔

## 常见问题排查

### 问题：监控脚本无法启动 Node.js 进程
**解决方案**：
- 检查 `package.json` 中的 `start` 脚本配置
- 手动运行 `npm start` 检查是否能正常启动
- 查看错误日志 `Logs/error.log` 获取详细信息

### 问题：自动化管理脚本无法更新版本号
**解决方案**：
- 确保 `package.json` 存在且格式正确
- 检查是否有足够权限修改文件
- 查看日志获取详细错误信息

### 问题：备份占用过多磁盘空间
**解决方案**：
- 调整 `BACKUP_RETENTION` 配置项，减少备份保留天数
- 手动清理旧备份目录
- 考虑使用差异备份替代完整备份
