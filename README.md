## 🎯 为什么选择 MTSCOS AI？

MTSCOS AI 智能考试系统是一个**自进化、自维护、自扩展**的下一代智能教育平台。不同于传统考试系统，它拥有：

- **🧠 41+ AI员工** - 专职AI专家团队，覆盖安全、教育、运维、优化等各个领域
- **🔧 自动修复引擎** - 8种修复能力，100%修复成功率，系统故障自动自愈
- **🛡️ 企业级安全** - 10+安全规则防火墙，AI智能漏洞分析与修复建议
- **🗄️ 分布式架构** - 20+独立数据库，智能路由，支持大规模并发
- **📱 全平台适配** - 响应式设计，移动端专用页面，PWA支持

这不仅是一个考试系统，更是一个**具备自我意识的智能教育生态**。

## 🚀 快速开始

### 环境要求
- Python 3.9+
- Flask 2.0+
- Redis 7.0+（可选，系统支持内存缓存降级）

### 安装步骤
```bash
cd flask-app
pip install -r requirements.txt
```

### 启动方式
```bash
# 模块化启动（推荐，完整功能）
python modular_start.py --port 8888

# 简化启动（快速预览）
python simple_start.py --port 8888
```

### 访问地址
- 系统首页: http://localhost:8888/
- 登录页面: http://localhost:8888/login
- 系统状态API: http://localhost:8888/api/system/status
- 增强管理器仪表板: http://localhost:8888/enhancement

## 🤝 贡献指南

欢迎加入 MTSCOS AI 项目！无论是代码贡献、文档完善、Bug报告还是功能建议，我们都非常欢迎。

### 代码规范

项目遵循以下规范文档，所有贡献必须严格遵守：

- [设计规范](.trae/rules/设计规范.md) - 统一UI设计标准和视觉风格
- [开发规则](.trae/rules/开发规则.md) - 统一开发标准和代码规范

### 分支管理策略

| 分支 | 用途 |
|------|------|
| `main` | 主分支，生产环境代码 |
| `develop` | 开发分支，集成所有功能 |
| `feature/xxx` | 功能分支，开发新功能 |
| `bugfix/xxx` | Bug修复分支 |
| `hotfix/xxx` | 紧急修复分支 |

### 提交信息规范

```
<类型>(<范围>): <描述>

<详细说明>
```

| 类型 | 说明 |
|------|------|
| `feat` | 新功能 |
| `fix` | Bug修复 |
| `docs` | 文档更新 |
| `style` | 样式修改 |
| `refactor` | 代码重构 |
| `test` | 测试代码 |
| `chore` | 构建/工具更新 |

示例：
```
feat(auth): 添加OAuth2登录支持

- 集成Google OAuth2
- 添加GitHub登录选项
- 更新登录页面UI
```

### 开发环境搭建

1. **克隆仓库**
```bash
git clone https://github.com/MTSCOS/MTSCOS_AI_Project.git
cd MTSCOS_AI_Project
```

2. **安装依赖**
```bash
cd flask-app
pip install -r requirements.txt
```

3. **配置环境变量**
```bash
cp .env.example .env
# 编辑 .env 文件，配置数据库路径等
```

4. **启动开发服务器**
```bash
python simple_start.py --port 8888
```

5. **运行测试**
```bash
python -m pytest
```

### 提交PR流程

1. **Fork仓库** - 在GitHub上Fork本仓库到自己的账户
2. **创建分支** - 基于 `develop` 分支创建新分支
3. **开发功能** - 实现功能或修复Bug，遵循代码规范
4. **提交代码** - 使用规范的提交信息
5. **推送分支** - 推送到自己的Fork仓库
6. **创建PR** - 在GitHub上创建Pull Request到 `develop` 分支
7. **代码审查** - 等待项目维护者审查
8. **合并分支** - PR通过审查后合并到 `develop`
