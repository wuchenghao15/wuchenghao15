# 即梦 Seedance 2.0 Prompt 最佳实践 (对比学习成果)

## ✅ 有效模式 (导演口吻)

### 模式 1: 自然语言描述运镜 + 画面
```
从"自然的密码"标题卡平滑向前推进, 画面自然过渡到数学公式卡片, 同一次连续相机运动贯穿全程
```
**关键**: 把运镜方式写出来 (推进/过渡/连续相机运动), 不是只写画面描述

### 模式 2: 分镜用数字列 (不是 JSON)
```
6个镜头依次生成, 每个8-10秒:
1. 开场大字标题: "2200年前的奇迹"
2. 水平时间线: 6个节点 + 红色高亮终点
3. 左右对比卡片: 左边统一前 vs 右边统一后
4. 三大基础设施要点列表
5. 遗产影响要点列表
6. CTA 互动引导页
```

### 模式 3: 完整旁白 + 自然语言分镜 (效果最好)
```
请生成一个关于「秦统一六国」的竖屏短视频 (9:16, 1080p, 50-60秒)。

【完整旁白台词】(普通话男声讲述):
公元前221年, 嬴政建立了中国第一个中央集权帝国——秦朝
他花了10年时间, 从22岁亲政到39岁灭六国, 完成统一大业
车同轨 书同文 统一度量衡——这三条让全中国第一次真正连成一个整体
修长城 筑驰道 建直道——这些工程在当时是世界上最先进的基础设施
秦朝虽然只存在15年, 但它定下的郡县制和中央集权, 影响了之后两千年的中国
秦砖汉瓦至今仍在, 统一的文字让我们读2000年前的书也能看懂

【6个分镜画面】(每个8-10秒):
1. 开场大字标题: "2200年前的奇迹", 副标题 "秦统一六国", 背景暖色渐变, 相机向前推进
2. 水平时间线: 6个节点 "前230灭韩→前228灭赵→前225灭魏→前223灭楚→前222灭燕→前221灭齐", 终点红色高亮 "前221→统一", 相机平滑过渡
3. 左右对比卡片: 左边"统一前 7种文字/7种度量衡/7条轨距", 右边"统一后 书同文/度同衡/车同轨"
4. 三大基础设施要点列表: 长城/驰道/直道
5. 遗产影响要点列表: 郡县制至今仍用/中央集权中华大一统/统一文字文明从未中断
6. CTA互动引导页: "秦朝虽然短但意义太重大 — 你还想了解秦朝哪个细节?"

【风格】现代简约知识科普风, 暖橙配色, 数据出现配简洁动画, 关键旁白配白色中文字幕, 前3秒必须是抓眼球的hook。

请直接开始生成, 不要问我确认。
```

## ❌ 无效模式 (AI 不喜欢)

1. 写 JSON 结构 —— AI 会忽略或解析错误
2. 产品需求文档格式 —— 太像 PRD, 不是导演指令
3. 只有画面描述没运镜指令 —— 画面静止, 没有动态
4. 太多技术参数混在画面描述里 —— AI 混乱

## 📊 效果对比

| 维度 | 导演口吻 Prompt (模式3) | JSON 结构 Prompt |
|------|------------------------|-----------------|
| 画面动态 | 每帧都在变 (37~95KB) | 静态卡片重复 (19~36KB) |
| 转场 | 自动平滑过渡 | ImageClip 硬切 |
| 旁白 | 自动匹配画面 | 需要手动对齐 |
