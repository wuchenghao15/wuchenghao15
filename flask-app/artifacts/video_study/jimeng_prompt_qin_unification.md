## 版本 A: 单镜头 10s 快生成 (推荐先试, 最稳)

```
请生成一个关于"秦统一六国"的竖屏短视频片段，时长10秒，9:16比例。

开场: 公元前221年，咸阳宫城楼上，身穿玄黑色冕服、头戴十二旒冕冠的嬴政（39岁，身形高大挺拔，目光锐利），手持象征王权的玉圭，缓缓转过身面向镜头。

运镜: 固定低位仰拍 → 缓慢向上推进 → 定格在嬴政面部特写。

旁白 (男声沉稳): "公元前221年，嬴政建立了中国第一个中央集权帝国——秦朝。"

背景: 身后是雄伟的秦朝宫殿建筑群，旗帜上写着"秦"字，风轻轻吹动旗帜。

整体风格: 历史正剧质感，暖金色调光影，电影级画面，人物面部细节清晰。
```

## 版本 B: 多镜头 15s 完整叙事 (复杂但有故事性)

```
请生成一个关于"秦统一六国"的竖屏短视频，时长15秒，9:16比例，包含以下镜头：

【镜头1-3秒 开场Hook】
画面: 身穿玄黑色冕服的嬴政站在咸阳宫城楼上，手持玉圭，目光锐利，身后旗帜写着"秦"字。他缓缓转身，抬起一只手向前指向远方。
运镜: 从远景缓慢推进到嬴政的中景，他的动作连贯有力量。
旁白 (男声): "公元前221年，嬴政完成统一。"

【镜头2-7秒 时间线蒙太奇】
画面: 六个国家的名字(韩→赵→魏→楚→燕→齐)像多米诺骨牌一样依次倒下，背景是动态的战争烟尘。最后一个"齐"倒下后，画面中央浮现大大的"秦"字。
运镜: 从左侧向右平移，跟随每个国家倒下的节奏。
旁白 (男声快速): "前230灭韩，前228灭赵，前225灭魏，前223灭楚，前222灭燕，前221灭齐。十年统一。"

【镜头3-11秒 统一后的变化】
画面: 三张卡片依次浮现——第一张文字"车同轨"配图展示统一后的道路车辙宽度一致；第二张"书同文"配图是统一的小篆文字；第三张"统一度量衡"配图是统一的标准度量器。
运镜: 每张卡片从画面下方向上滑入，停留2秒后向右滑出。
旁白 (男声): "车同轨，书同文，统一度量衡——这三条让全中国第一次真正连成一个整体。"

【镜头4-15秒 CTA结尾】
画面: 身穿玄黑色冕服的嬴政(和镜头1同一人物形象)再次出现，站在长城修建工地上，身后是正在修筑的长城墙体，工人们在忙碌。他转头看向镜头，微微点头。
运镜: 从嬴政侧面跟拍，绕到正面定格。
旁白 (男声放慢): "秦朝虽然只存在15年，但它定下的郡县制，影响了之后两千年的中国。"

整体风格: 历史正剧质感，暖橙金色调，电影级光影，人物统一穿玄黑色冕服，嬴政统一形象39岁高大挺拔。每个镜头之间有0.3秒的平滑转场。
```

## 版本 C: 首帧图 + 视频两步法 (效果最好, 但需要两步操作)

### Step 1: 先在即梦 AI 图片生成里出一张首帧图

**Prompt (粘到即梦图片生成)**:
```
公元前221年，咸阳宫城楼上，身穿玄黑色冕服、头戴十二旒冕冠的嬴政(39岁，身形高大挺拔，目光锐利)，手持象征王权的玉圭，站在高台之上。身后是雄伟的秦朝宫殿建筑群，城墙上插着写有"秦"字的黑色旗帜。画面风格: 历史正剧质感，暖金色调，电影级光影，细节丰富，1080p。竖屏9:16构图。
```

**选一张满意的保存** → 用它做视频生成的首帧图。

### Step 2: 即梦视频生成 (选首帧图 + Seedance 2.0 模型)

**Prompt (粘到即梦视频生成对话框)**:
```
以这张图片为首帧，生成一个15秒的竖屏视频。

开场: 身穿玄黑色冕服的嬴政手持玉圭，缓缓转过身面向镜头，身后旗帜轻轻飘动。
运镜: 固定低位仰拍 → 缓慢向上推进 → 定格面部特写。
旁白 (男声沉稳): "公元前221年，嬴政建立了中国第一个中央集权帝国——秦朝。"

接下来画面切换: 六个国家名字(韩→赵→魏→楚→燕→齐)像多米诺依次倒下，背景烟尘，最后"秦"字浮现。
运镜: 从左向右平移跟随节奏。
旁白 (男声快速): "前230灭韩到前221灭齐，十年统一。"

再切换: 三张文字卡片依次浮现"车同轨"配图道路/ "书同文"配图文字/ "统一度量衡"配图标准器。
运镜: 每张卡片从下方滑入，停留2秒滑出。
旁白 (男声): "这三条让全中国第一次真正连成一个整体。"

最后: 身穿玄黑色冕服的嬴政(和开头同一人物)站在长城工地，身后工人忙碌，他转头看向镜头点头。
运镜: 侧面跟拍绕到正面定格。
旁白 (男声放慢): "秦朝虽然只存在15年，但郡县制影响了之后两千年。"

人物一致性要求: 所有镜头中嬴政统一穿玄黑色冕服、39岁高大挺拔形象。画面风格暖橙金色调历史正剧质感。镜头间平滑转场。
```

## 使用指南

| 步骤 | 操作 | 为什么 |
|------|------|--------|
| ① | 打开 jimeng.jianying.com | 即梦 Web 版所有人都能用 (CLI 需要会员) |
| ② | 选 Seedance 2.0 模型 | 2.0 比 2.1 多镜头叙事能力更强 |
| ③ | 比例选 9:16 | 抖音/B站/小红书都是竖屏 |
| ④ | 粘贴上面的 Prompt | Seedance 2.0 能识别自然语言分镜格式 |
| ⑤ | 有首帧图的话先上传再生成 | 锁定人物形象和画面风格, 后续镜头更稳定 |
| ⑥ | 生成后下载 → 剪映合成 BGM/音效/遮罩水印 | 即梦右下角有水印, 用剪映画面缩放遮掉 |

## 即梦 Prompt 黄金法则 (从官方案例学来的)

| ✅ 即梦喜欢 | ❌ 即梦讨厌 |
|------------|------------|
| 讲故事口吻自然语言 | JSON 结构 / 产品需求文档 |
| 每个镜头带**运镜方式** | 只有画面描述没运镜 |
| 人物特征**每个镜头重复** (穿什么衣服/多大年纪) | 后面的镜头只写"嬴政" (AI 会变人) |
| 台词**带说话人 + 引号** ("他说：...") | 只写台词不知道谁在说 |
| 空间音效描述 (脚步声从左侧) | 无音效提示 |
| 分镜数 ≤ 4 个 (10秒视频) | 分镜数太多 (AI 随机失控) |
| 先出**首帧图**再生成视频 | 直接文生图 (风格不稳定) |
