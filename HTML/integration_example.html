MTSCOS - 日志系统集成示例

集成说明

此页面展示了如何在 MTSCOS 系统中集成新的日志动作拐点记录系统。

步骤 1: 引入日志跟踪脚本

<script src="/assets/js/core/action-tracking.js"></script>

步骤 2: 自动记录的事件

  • 页面加载和卸载
  • JavaScript 错误
  • 资源加载错误
  • 用户点击事件
  • 表单提交事件

步骤 3: 手动记录事件

// 记录自定义动作 actionTracker.logCustomAction('ACTION_NAME', { /* 自定义数据 */ }); // 记录状态变更 actionTracker.logStateChange('stateType', 'oldState', 'newState');
